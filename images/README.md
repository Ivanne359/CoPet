# CoPet Images Directory 🐾

This folder is ready for your images!

### 1. Logo Image
- Place your logo file here, for example: `images/logo.png`.
- In `index.html`, update the `<img>` src:
  ```html
  <img src="images/logo.png" alt="CoPet Logo" class="brand-logo-img">
  ```

### 2. Hero Pet Bowls Picture
- Place your high-resolution picture here, for example: `images/bowls.png`.
- In `index.html`, update the hero image src:
  ```html
  <img src="images/bowls.png" alt="CoPet Handcrafted Pet Bowls" class="hero-product-img">
  ```

Currently, high-fidelity SVGs (`logo.svg` and `hero-bowls.svg`) are already provided so your site looks 100% complete right out of the box!
